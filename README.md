# IR Fellow EBIR Fieldbook

Static GitHub Pages site for an interventional radiology fellowship / EBIR reference.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. GitHub will show the public Pages URL once deployed.

The web app entry point is `index.html`.
